# Registros de sessão

Este diretório armazena registros necessários para retomar trabalhos relevantes.

Um registro deve incluir:

- data e unidade;
- objetivo;
- atividade executada;
- evidências;
- resultado da revisão;
- bloqueios;
- próxima ação.

Não é obrigatório criar um arquivo para conversas sem consequência acadêmica ou operacional.
