# Revisões e avaliações

Este diretório armazena pareceres de entregas e avaliações.

Cada revisão deve identificar:

- módulo, unidade ou avaliação;
- critérios aplicados;
- evidências examinadas;
- requisitos atendidos;
- correções necessárias;
- decisão;
- vínculo com commit ou pull request quando existir.
