# Ambiente

Este diretório será desenvolvido durante o M00.

Aqui ficarão somente artefatos necessários para instalar, operar, validar e recuperar o ambiente do curso, como documentação, configuração declarativa e exemplos seguros de variáveis.

## Regras

- o arquivo `.env` real nunca será versionado;
- volumes, bancos locais e backups não serão versionados;
- `.env.example` poderá conter apenas nomes e valores fictícios;
- configurações devem ser justificadas e testadas;
- a estrutura será criada progressivamente pelas unidades do M00.

Nenhuma configuração técnica foi definida antecipadamente nesta implantação de governança.
